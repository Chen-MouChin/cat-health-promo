全台動物醫院查詢

貓半夜突然不舒服，最急的是找到現在還開著的醫院。貓健康站把全台的動物醫院整理在同一頁。

怎麼用

  • 選縣市，或搜尋院名、地址、區名
  • 半夜或假日，勾「只看夜間急診」
  • 想找專門看貓的醫院，勾「只看貓專科」
  • 用手機開，可以定位找附近的醫院

你會看到什麼

  • 醫院的地址、電話，點一下就能打電話或開地圖
  • 有夜間急診的醫院會另外標出來

資料從哪來

  • 醫院名單來自農業部與縣市政府的公開資料，全台 22 縣市（連江縣沒有登記的動物醫院）
  • 出發前先打電話確認，營業時間可能會變動

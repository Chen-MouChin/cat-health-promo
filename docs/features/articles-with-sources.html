貓健康站・網站功能

每篇文章都附出處

網路上的養貓資訊說法很多，常常不知道該信哪個。貓健康站的每篇文章，都把說法的來源寫出來。

怎麼用

  • 從網站首頁或分類找到想看的主題
  • 先看文章開頭的「30 秒重點」，趕時間看這段就夠
  • 段落後面的小數字點下去，就是這句話的出處

你會看到什麼

  • 每篇都有「哪些情況建議帶去看醫生」和「居家能做的事」，看完知道下一步要做什麼
  • 文末列出全部出處，附原文連結
  • 專有名詞第一次出現會寫中文，括號附英文，例如國際貓科醫學會（ISFM）

資料從哪來

  • 出處以國際獸醫指引、大學獸醫中心和同儕審查期刊為主，全部收在學術文獻庫
  • 文獻庫裡標「已審核」的，是逐項核對過原文的
  • 誰在寫、怎麼審核、怎麼更正，寫在編輯方針

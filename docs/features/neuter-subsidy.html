各縣市結紮補助一次查

很多縣市有家貓結紮補助，但每個縣市的金額、條件和申請方式都不一樣。貓健康站把 22 個縣市整理在同一頁。

怎麼用

  • 找到你住的縣市
  • 看公貓、母貓的補助金額和申請條件
  • 照上面寫的方式申請，留意期限

你會看到什麼

  • 各縣市的補助金額、條件、申請方式和期限
  • 有些縣市另外有免費的活動，也一起列出來

資料從哪來

  • 依各縣市政府的公告整理，頁面上寫了查詢日期
  • 補助常常額滿或改辦法，申請前先打電話問縣市的動物保護單位

想看原文，或想知道某個說法到底是誰講的？貓健康站文章引用的資料，全部收在文獻庫，一筆一筆附上中文摘要。

怎麼用

  • 搜尋關鍵字，或依主題、來源篩選
  • 先看中文摘要，再決定要不要讀原文
  • 點連結到原文；有些網站的使用條款只允許連到首頁，這種會請你用英文標題搜尋

你會看到什麼

  • 國際獸醫組織的指引：世界小動物獸醫協會（WSAVA）、美國動物醫院協會（AAHA）、美國貓科獸醫師協會（AAFP，現名 FelineVMA）、國際貓科醫學會（ISFM）
  • 大學獸醫中心的衛教資料：康乃爾大學貓健康中心（Cornell）
  • 同儕審查期刊的論文
  • 政府機關的資料：農業部、美國食品藥物管理局、全國法規資料庫

資料從哪來

  • 都是貓健康站文章實際引用的來源，文章頁尾的出處清單都查得到
  • 標「已審核」的，是逐項核對過原文的
  • 怎麼挑來源、怎麼審核，寫在編輯方針
